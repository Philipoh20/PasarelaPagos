04 / SEGURIDAD & ROLES

CONTROL DE ACCESO BASADO EN ROLES

Reglas de autorización del sistema. Los intentos de acceso o eliminación no autorizados son bloqueados con código 403 Forbidden.

ROL: ADMIN ACCESO TOTAL AL SISTEMA

ADMINISTRADOR

Responsable de supervisión, modificación de pagos y administración de usuarios.

  • ✓ Crear, consultar, modificar y eliminar pagos.
  • ✓ Emitir facturas y anularlas o eliminarlas.
  • ✓ Consultar el listado completo de usuarios en SQLite (GET /usuarios).
  • ✓ Asignar rol de administrador a otros usuarios.
ROL: USUARIO OPERACIÓN SEGURA ESTÁNDAR

USUARIO REGULAR

Cliente o usuario operativo del sistema con permisos no destructivos.

  • ✓ Crear pagos simulados y consultar pagos.
  • ✓ Emitir facturas en formato JSON e inspeccionarlas.
  • ✕ NO puede modificar pagos (Retorna 403 Forbidden).
  • ✕ NO puede eliminar pagos (Retorna 403 Forbidden).
  • ✕ NO puede eliminar facturas (Retorna 403 Forbidden).
  • ✕ NO puede ver la lista de usuarios (Retorna 403 Forbidden).
